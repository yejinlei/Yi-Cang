四大根类之间由跨类对象属性打通：

- 实体资源类 ⇄ 典籍类（作者/版本）

```

 └─ 医经类 ──┬─ 《黄帝内经》 ─── 成书年代 / 版本源流 / 馆藏
             └─ 《难经》
```

L4 每个典籍实体挂：
- `belongsToYizangCategory` 指回 L3 类目
- `citesYizangBook` 指向前代典籍，形成学术传承网

## 四、L5–L6：篇章拆解与知识元提取

```
《黄帝内经》
 ├─ L5《素问》81 篇
 │    └─ 例：《阴阳应象大论》篇
 │         └─ L6 知识元
 │              ├─ 概念元：阴阳、五行、藏象
 │              ├─ 证候元：某某证
 │              └─ 治法元：某某治则

      └─ 例：《九针十二原》篇

```

L6 严格按 **病 → 脉 → 证 → 治 → 方 → 药** 六段链条组织。

## 五、L7：条文异文层（附加属性落点）

条文元保留原始文言文，不改字。挂载附加属性：
- 异体字映射：原文异体字 ➜ 规范字
- 生僻字注音：拼音 + Unicode 码点
- 语义差异说明：如 俞 / 输 / 腧 的历代区分
- 白话文翻译：独立属性，不替换原文
- 校勘记录：他版本差异
- sourcePosition：页码 / 卷次定位

这一层是唯一承载"生僻字、异体字、白话翻译"的地方，**单字不做顶级类**，只作属性值存在。

## 八、约束与边界

- **层级红线**：类层级最多 7 层，单字不设顶级类，防止推理机节点爆炸。
- **逻辑校验**：五行生克自洽、中药四气不双值、方剂组成完整，靠推理机自动查冲突。
- **民族医药隔离**：藏医等独立子本体不强行并入中医概念树，仅建跨体系映射表。
- **原文优先**：L7 永远保留文言原文，白话译文只作附加属性，不作为知识元定义依据。
